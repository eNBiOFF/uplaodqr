# lan-share

Передаёт архив (или любой другой файл) на другое устройство в той же сети Wi-Fi. Node.js 18.3+ нужен только на устройстве, которое отправляет файл; на принимающем достаточно браузера.

```
node share.js archive.zip
```

Скрипт выведет ссылку вида `http://192.168.1.29:8080/ab3k7x`. Введите её в браузере на втором устройстве, и скачивание начнётся сразу.

Ссылка работает, пока запущен скрипт, и открывается сколько угодно раз. Остановить раздачу можно через `Ctrl+C`, а при следующем запуске создаётся новая ссылка.

Параметры:

- `--port 9000` — использовать этот порт (по умолчанию 8080 или следующий свободный).
- `--ip 192.168.1.29` — подставить в ссылку этот адрес, если автоматически выбран не тот.

## Если ссылка не открывается

- **Брандмауэр Windows.** Разрешите Node.js входящие подключения для того профиля сети (частная или общедоступная), который сейчас у вашего Wi-Fi.
- **VPN.** VPN на любом из устройств может мешать соединению; попробуйте его отключить.
- **Изоляция клиентов.** Гостевые и публичные Wi-Fi часто запрещают устройствам видеть друг друга.

Трафик идёт по HTTP без шифрования, поэтому используйте скрипт только в сети, которой доверяете.
